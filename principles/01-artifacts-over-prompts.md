# Artifacts over prompts

A prompt is only useful if it produces a durable artifact.

Good agentic work ends in something inspectable:

- a decision memo
- a PR or patch
- a project pulse
- an issue tree
- a test result
- a checklist
- a postmortem
- a reusable procedure

Bad agentic work ends in vibes: long chat, no artifact, no decision, no next
step, no verification.

## Standard

Every workflow should define:

1. the artifact it produces
2. who reviews it
3. what verification is required
4. what action follows
