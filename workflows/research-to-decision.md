# Research-to-decision pipeline

Use this workflow when research must end in a recommendation, not a pile of
links.

## Risk level

Read-only unless the resulting decision triggers an external action.

## Process

1. Define the decision to be made.
2. Search broad enough to avoid one-source bias.
3. Prefer primary sources and credible practitioner reports.
4. Separate facts, claims, and opinions.
5. Summarize tradeoffs.
6. Recommend one path, with alternatives.
7. Name the approval or next action required.

## Output artifact

```md
# Decision memo: <topic>

## Decision
<what we need to decide>

## Summary
<3-5 bullets>

## Evidence
- Source — relevant finding — confidence

## Options
1. Option A — pros/cons
2. Option B — pros/cons

## Recommendation
<clear call>

## Next action
<what to do now>
```

## Failure modes

- Confusing popularity with fit.
- Reporting claims without source quality.
- Ending with “it depends” instead of a recommendation.
