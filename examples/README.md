## Publication rules

- Do not replace fictional data with real clients, employers, accounts, or
  private screenshots.
- Keep URLs on `example.com` unless a public source is required for a workflow.
- Use fake analytics, pixel, conversion, customer, ad account, campaign,
  catalog, file, calendar, and workspace IDs.
- Run `bun cli/aw.ts publication-scan` before committing changes.
