La mayoria de los equipos no necesita otro dashboard. Necesita una forma mas
tranquila de notar que cambio.

Las notas semanales funcionan porque crean un ritmo pequeno: que se entrego,
que nos bloqueo, que nos sorprendio y que necesita una decision.

```ts
type WeeklyNote = {
  shipped: string[];
  blocked: string[];
  decisions: string[];
};
```

## Hacer visible el trabajo importante

La mejor nota semanal no es un reporte de estado. Es un mapa de atencion.

Si un proyecto aparece una y otra vez en la seccion de bloqueos, probablemente
necesita una decision. Si una pequena victoria se repite, puede ser un proceso
que vale la pena conservar.
