# Landing-page decisions

A conversion landing page serves one offer, audience and primary action. Preserve the project's established visual system and the user's choices. A small copy or component change does not require a new strategy or design system.

- For positioning, page structure and conversion copy, read the relevant sections of strategy (reference absent from the checked upstream snapshot).
- When a new page needs visual defaults, use the relevant sections of the optional visual recipe (reference absent from the checked upstream snapshot). Its values are examples, not authority over another project's design.

Use the existing brief before asking questions. Ask only when missing information materially changes the task; continue useful independent work. Complete the requested output and relevant checks without adding a redesign, commit or publication step.
